# Carona Solidária · João Pessoa

**Este endereço agora redireciona para o site único da Carona Solidária:** <https://caronasolidaria.github.io/?cidade=jp>

Quem abre <https://caronasolidaria-jp.github.io/> (ou qualquer página dele) é levado para lá, já em João Pessoa. O cadastro de motorista guardado no celular vai junto, sem precisar se cadastrar de novo.
